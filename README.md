# Optical Calculator

머신비전 광학 계산기. PC 브라우저와 휴대폰에서 같은 코드로 동작하는 PWA입니다.

## 실행

`run.bat` 을 더블클릭하면 서버가 뜨고 브라우저가 열립니다. 창을 닫으면 서버도 꺼집니다.

직접 띄우려면:

```bash
python -m http.server 8123
```

- 앱: http://127.0.0.1:8123/index.html
- 공식 검증: http://127.0.0.1:8123/verify.html

ES 모듈을 쓰기 때문에 `index.html` 을 파일로 직접 열면(`file://`) 브라우저가 스크립트 로드를
막습니다. 반드시 서버를 거쳐야 합니다.

휴대폰에서 볼 때는 PC와 같은 Wi-Fi에 접속한 뒤 PC의 LAN 주소로 들어갑니다.
`run.bat` 이 창에 후보 주소를 출력합니다. `192.168.*` 또는 `10.*` 로 시작하는 것이 보통 맞고,
`172.*` 는 WSL·Hyper-V 가상 어댑터라 대개 연결되지 않습니다.
윈도우 방화벽이 물으면 허용해야 합니다.

`verify.html`은 UI 없이 계산 코어만 확인합니다. 공식을 고친 뒤에는 이 페이지가 전부 PASS인지
먼저 보고 넘어가세요.

## 구조

```
core/
  units.js      단위 변환, 표시용 반올림, 표준 초점거리 목록
  profile.js    장비 프로필 · 즐겨찾기 (localStorage)
  registry.js   계산기 등록소, 대분류 정의, 검색
  render.js     화면 렌더러 (전 계산기 공용) + 해시 라우팅
calc/
  lens.js       렌즈 대분류 계산기 정의 + 공식
pwa/
  icon.svg
manifest.json   설치 정보
sw.js           오프라인 캐시
verify.html     공식 검증
```

핵심은 **계산기가 화면이 아니라 정의 객체라는 점**입니다. `calc/*.js`에 객체 하나를 추가하면
홈·대분류·검색·즐겨찾기·상세 화면이 전부 자동으로 따라옵니다. 화면 코드는 건드리지 않습니다.

## 계산기 추가하는 법

`calc/` 에 정의 객체를 넣고 `core/registry.js`의 `RAW` 배열에 합칩니다.

```js
{
  id: 'my-calc',
  category: 'camera',              // CATEGORIES 의 id
  name: '표시 이름',
  summary: '한 줄 설명',
  tags: ['검색어', '검색어'],
  related: ['다른-계산기-id'],
  formula: '화면 하단에 보일 수식',
  en: 'English Name',              // 국문 옆에 흐리게 붙는 통용 영문 용어
  inputs: [
    { key: 'a', label: '라벨', en: 'Label', unit: 'mm', default: 10, min: 0, step: 0.1,
      profile: 'workingDistance' },   // profile 키를 주면 장비 프로필이 기본값을 채운다
  ],
  outputs: [
    { key: 'b', label: '라벨', en: 'Label', unit: 'mm', digits: 2, primary: true },
  ],
  compute(v) { return { b: v.a * 2 }; },       // 순수 함수. DOM 을 참조하지 않는다
  warn(v, o) { return [{ level: 'warn', text: '…' }]; },  // level: info | warn | danger
}
```

입력 방향이 여러 개인 계산기는 `inputs`/`outputs`/`compute` 대신 `modes` 배열을 쓰면
상단에 탭이 생깁니다. `calc/lens.js`의 `lens-select`가 예시입니다.

`compute` 가 반환하는 키 중 `_` 로 시작하는 것은 화면에 표시되지 않습니다.
`warn` 에 넘길 중간값을 담는 용도로 씁니다.

### 영문 용어 규약

`en` 은 필수는 아니지만 **계산기·모드·모든 입출력 항목에 붙이는 것을 원칙**으로 합니다.
렌즈와 카메라 스펙시트가 전부 영문이라, 국문 라벨만 있으면 스펙시트와 대조가 안 됩니다.

- 업계 통용 표기를 그대로 씁니다. `FOV`, `WD`, `DOF`, `CoC`, `Airy Disk`, `F-number`
- 직역하지 않습니다. 시야 → `Field of View` 가 아니라 실제로 쓰는 `FOV`
- 검색은 `en` 값까지 훑으므로 `Nyquist`, `CoC` 같은 영문으로도 계산기가 찾힙니다

## 배포

정적 파일만 있으므로 아무 정적 호스팅에나 올리면 됩니다.

- GitHub Pages: 저장소 push 후 Settings → Pages → 브랜치 지정
- 휴대폰: 배포 주소 접속 → 브라우저 메뉴 → "홈 화면에 추가"
- PC: Chrome/Edge 주소창 우측 설치 아이콘 → "앱으로 설치"

`sw.js` 덕분에 한 번 열어두면 오프라인에서도 동작합니다. 파일을 고쳐 재배포할 때는
`sw.js` 상단의 `CACHE` 버전 문자열을 올려야 사용자에게 새 버전이 내려갑니다.

서비스 워커는 `https` 또는 `localhost` 에서만 등록됩니다. 사내망 http 주소로 배포하면
계산은 정상 동작하지만 오프라인 캐시는 걸리지 않습니다.

## 현재 범위

렌즈 대분류 3개가 들어가 있습니다.

| 계산기 | 내용 |
| --- | --- |
| 렌즈 선정 | 초점거리 / 시야 / 작동거리 3방향 계산, 제약축 판정, 표준 렌즈 역산 |
| 피사계심도 DOF | 허용 착란원 기반 심도, 초점심도, 회절 스팟 비교 |
| 해상도 · 검출 한계 | µm/px, 검출 한계, 나이퀴스트, 종횡비 불일치 경고 |

카메라 · 조명 · 기하 · 파동 대분류는 홈에 "준비 중"으로 표시되며 아직 계산기가 없습니다.

## 계산 규약

- 박막렌즈 근축 근사 기준입니다. 주점 간격을 반영하지 않으므로 실제 렌즈에서는 오차가 있습니다.
- 센서 크기는 포맷 프리셋(1/2", 2/3" 등)이 아니라 `픽셀수 × 픽셀 크기`로 계산합니다.
- 가로·세로 요구 배율이 다를 때는 **작은 쪽**을 택합니다. 큰 쪽을 쓰면 반대 축이 시야를 벗어납니다.
- 피사계심도의 허용 착란원 기본값은 픽셀 크기 × 2입니다. 현장 기준이 다르면 입력에서 배수를 바꾸세요.
- 회절 파장은 가시광 550 nm 고정입니다.
